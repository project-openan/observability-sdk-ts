# 开发指南

## 构建

安装依赖并构建 ESM 包：

<pre><code>npm install
npm run build
npm run typecheck:examples</code></pre>

项目使用严格 TypeScript、NodeNext 模块解析并输出声明文件。构建会把 YAML 信号配置复制到编译目录，供安装后的 SDK 加载。

## 信号定义

`src/config` 下的三个文件定义支持的属性、Metric、Workflow/Agent 事件、A2A 操作和 A2A-T 扩展。请保持这些文件与 Java、Python SDK 一致。公开信号发生变化时，更新对应配置版本、中英文 API 参考和开发指南。删除或收紧已发布的信号、属性、必填字段或 Metric 维度属于破坏性变更。

A2A Span 使用 Java SDK 中的操作名称，例如 `SendMessage`、`SendStreamingMessage`、`GetTask` 和推送通知方法。`GetExtendedAgentCard` 与 `SendPushNotification` 仅支持 Client；`SendStreamingMessage-negotiation` 仅支持 Server。流事件和流错误 Span 会将父级保留为 Span Link。

## Exporter 与 Context

SDK 自行管理 Trace、Metric 和 Log Provider，不会替换应用的全局 Tracer、Meter 或 Logger Provider。只有尚未注册 Context Manager 时，SDK 才会安装 OpenTelemetry 异步上下文管理器。运行时切换 Exporter 时会保留在途请求，并在请求结束后关闭旧 Exporter。

## Commit 和 PR

- 使用 Conventional Commit，例如 `feat(sdk): add TypeScript observability SDK`。
- Commit 使用 DCO 签署：`git commit -s -m "..."`。
- 从个人 fork 提交 PR，不直接向上游仓库推送 Commit。
- PR 标题和描述使用英文，并说明执行过的验证。
